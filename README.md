# 英語 EXP クエスト

英語の学習時間を記録して、EXP、レベル、ランク、実績、称号、デイリークエストを楽しむローカル Web アプリです。

## 起動方法

1. このフォルダーを開き、PowerShell で `py -m http.server 8000` を実行します。
2. ブラウザーで `http://localhost:8000` を開きます。

Python がない場合は、`index.html` をブラウザーで直接開いても利用できます。記録はブラウザーのローカルストレージに保存されます。

## HTTPS で公開する場合

GitHub Pages に `index.html` を公開すると HTTPS の URL で利用できます。各端末のデータはそれぞれのブラウザーに保存され、自動同期されません。端末間で記録を移す場合は、アプリの設定からバックアップを保存・復元してください。

## ゲームのルール

- 実際の学習記録 1 分につき 1 EXP を獲得します。クエスト報酬は EXP に含めず、コインで管理します。
- ホーム画面の勉強タイマーで計測を開始し、終了すると完了した分数を選んだカテゴリの学習記録として自動加算します。計測中にページやブラウザーを閉じても経過時間を保持し、次回アクセス時に続きから反映します。一時停止中は時間を加算しません。1 分未満で終了した計測は記録しません。
- レベル n から次のレベルに必要な EXP は `50 + 15 × (n − 1)` です。累計 EXP をレベル内 EXP から二分探索で計算します。
- ランクは累計 EXP で決まり、ランクの閾値は `index.html` の `RANKS` にあります。
- 実績の条件と称号の初期コレクションは `index.html` 内で設定します。
- デイリークエストでもらったコインは、ショップで13種類のプロフィールフレームと3種類のショップ限定称号の購入に使えます。価格帯は40〜18,000コインで、購入済みフレームはプロフィールに装備、称号はコレクション画面から設定できます。
- 毎週入れ替わるボスは、その週の学習分数でHPが減ります。週60・180・360分の節目でコインを獲得し、未達成のペナルティはありません。
- 冒険マップは累計30〜10,000分で8つのエリアを開拓します。宝箱のコインは一度だけ獲得でき、既存の勉強記録も進行に反映されます。
- 3種類の相棒を累計勉強時間で解放し、それぞれ5段階まで成長させられます。相棒を選んで一緒に冒険できます。
- アプリの保存データ形式は `version: 1` です。設定画面で JSON を書き出し・復元できます。

## 検証

JavaScript の構文確認と、レベル境界、ランク境界、91 種の実績、学習記録と EXP、タイマーの開始・一時停止・再開・保存・自動記録、デイリー／ウィークリーボス報酬、冒険マップの一度限りの報酬、相棒の解放と成長、コインショップでの購入・装備、記録取り消し、バックアップ検証を確認しています。

## 保存と同期

データは現在のブラウザーにのみ保存されます。アカウント機能や複数端末の自動同期はありません。ブラウザーのデータを消去する前に、設定画面からバックアップを保存してください。
